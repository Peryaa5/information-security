# WireGuard VPN Server on VPS with Docker

## Описание проекта

Учебный проект по развёртыванию VPN-сервера на базе WireGuard.  
В рамках работы был изучен принцип работы VPN, основные виды VPN-сетей и протоколы, после чего был настроен VPN-сервер на VPS с использованием Docker и веб-интерфейса управления WireGuard.

Проект выполнен в рамках учебной практики по направлению информационной безопасности.

## Цель работы

Получить теоретические знания и практические навыки, необходимые для установки, настройки и проверки работы VPN-систем.

## Что было сделано

- изучены основные типы VPN:
  - Remote Access VPN;
  - Intranet VPN;
  - Extranet VPN;
- рассмотрены VPN-протоколы:
  - PPTP;
  - L2TP/IPsec;
  - IPsec;
  - OpenVPN;
  - WireGuard;
- арендован и подготовлен VPS-сервер;
- выполнено подключение к серверу по SSH;
- установлен Docker;
- развёрнут WireGuard VPN-сервер в Docker-контейнере;
- настроен веб-интерфейс управления WireGuard;
- создан клиентский конфигурационный файл;
- выполнено подключение клиента к VPN;
- проверено изменение IP-адреса после подключения к VPN.

## Используемые технологии

- Linux VPS
- SSH
- MobaXterm
- Docker
- WireGuard
- wg-easy
- VPN
- TCP/IP
- 2ip.ru для проверки внешнего IP

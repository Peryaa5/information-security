# Теоретическая часть: VPN и основные протоколы

## Что такое VPN

**VPN** (*Virtual Private Network*) — технология, которая позволяет создавать защищённое соединение поверх другой сети, например интернета.

VPN используется для защиты передаваемых данных, безопасного удалённого доступа к ресурсам и повышения конфиденциальности сетевого соединения.

При использовании VPN пользователь подключается не напрямую к нужному ресурсу, а через VPN-сервер. Трафик между клиентом и VPN-сервером передаётся по защищённому каналу.

## Принцип работы VPN

Общий принцип работы VPN:

1. Пользователь запускает VPN-клиент.
2. Клиент устанавливает соединение с VPN-сервером.
3. Между клиентом и сервером создаётся защищённый туннель.
4. Сетевой трафик пользователя направляется через VPN-сервер.
5. Внешние ресурсы видят IP-адрес VPN-сервера, а не исходный IP-адрес пользователя.

## Основные виды VPN

### Remote Access VPN

**Remote Access VPN** используется для удалённого подключения отдельных пользователей к сети.

Пример: сотрудник подключается из дома к корпоративной сети компании.

### Intranet VPN

**Intranet VPN** применяется для объединения нескольких внутренних сетей одной организации.

Пример: соединение офисов одной компании через защищённые каналы связи.

### Extranet VPN

**Extranet VPN** используется для организации защищённого доступа между сетями разных организаций.

Пример: защищённое соединение между компанией и её партнёрами.

## VPN-протоколы

VPN-протокол определяет, как именно создаётся туннель, как выполняется аутентификация и как защищается трафик.

### PPTP

**PPTP** — один из первых VPN-протоколов. Он прост в настройке, но считается устаревшим и недостаточно безопасным.

Преимущества:

- простая настройка;
- высокая скорость.

Недостатки:

- слабая защита;
- не рекомендуется для современных защищённых соединений.

### L2TP/IPsec

**L2TP** отвечает за туннелирование, а **IPsec** используется для защиты и шифрования данных.

Преимущества:

- поддерживается многими системами;
- обеспечивает более высокий уровень безопасности, чем PPTP.

Недостатки:

- может работать медленнее из-за двойной инкапсуляции;
- сложнее в настройке.

### IPsec

**IPsec** — набор протоколов для защиты IP-трафика. Может работать в транспортном и туннельном режимах.

Преимущества:

- высокий уровень безопасности;
- подходит для соединения сетей.

Недостатки:

- более сложная настройка;
- может требовать дополнительной конфигурации сетевого оборудования.

### OpenVPN

**OpenVPN** — популярный VPN-протокол с открытым исходным кодом. Использует TLS и поддерживает разные алгоритмы шифрования.

Преимущества:

- высокий уровень безопасности;
- гибкая настройка;
- поддержка разных платформ.

Недостатки:

- настройка может быть сложнее, чем у WireGuard;
- скорость обычно ниже, чем у WireGuard.

### WireGuard

**WireGuard** — современный VPN-протокол, ориентированный на простоту, безопасность и высокую производительность.

Преимущества:

- высокая скорость;
- простая архитектура;
- современная криптография;
- удобная настройка.

Недостатки:

- меньше встроенных возможностей тонкой настройки по сравнению с OpenVPN;
- требует аккуратного управления ключами.

## Преимущества VPN

- защита данных при передаче через интернет;
- безопасное использование общественных Wi-Fi сетей;
- удалённый доступ к корпоративным ресурсам;
- возможность скрыть исходный IP-адрес;
- объединение удалённых сетей и устройств.

## Недостатки VPN

- возможное снижение скорости соединения;
- зависимость от качества VPN-сервера;
- необходимость правильной настройки;
- необходимость защищать ключи и конфигурационные файлы;
- возможные юридические ограничения в отдельных странах или организациях.

## Почему в работе был выбран WireGuard

WireGuard подходит для учебного проекта, потому что он современный, быстрый и относительно простой в настройке. Его удобно разворачивать на VPS, а управление клиентами можно упростить с помощью веб-интерфейса `wg-easy`.

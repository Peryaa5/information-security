### Настройка сетевых служб: DHCP, DNS, HTTP, FTP

Проект в Cisco Packet Tracer: настройка базовых сетевых служб в локальной сети. Server1 используется как DNS, Web и FTP-сервер, Server2 — как DHCP-сервер, а клиентский ПК получает параметры TCP/IP через DHCP, открывает сайт по доменному имени и проверяет работу FTP.

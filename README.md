# information-security
Проекты по информационной безопасности: курсовые работы, учебные проекты, практические лабораторные работы, сетевые настройки, SOC-анализ, CTF-разборы и исследования по кибербезопасности.

## Разделы

### [Networks](networks/)

Проекты по компьютерным сетям и сетевой безопасности.


### [SOC and Incident Response](soc-and-incident-response/)

Практические материалы по SOC, анализу инцидентов и Blue Team.

### [CTF Writeups](ctf-writeups/)

Разборы отдельных заданий с CTF-соревнований.

### [Cryptography](cryptography/)

Проекты по криптографии и криптографической защите информации.


### [VPN](vpn/)

Проекты по настройке VPN и защищённого удалённого доступа.

### [Biometrics](biometrics/)

Учебные проекты по биометрии и компьютерному зрению.

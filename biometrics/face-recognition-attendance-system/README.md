# Система учета посещаемости с распознаванием лиц

Проект на Python для автоматического учета посещаемости студентов с использованием технологии распознавания лиц.  
Система получает изображение с веб-камеры, распознает зарегистрированных пользователей и фиксирует их присутствие в CSV-файле.

## Что было реализовано

- захват видеопотока с веб-камеры;
- загрузка базы изображений зарегистрированных пользователей;
- кодирование лиц с помощью библиотеки `face_recognition`;
- сравнение лиц из видеопотока с базой известных лиц;
- определение зарегистрированных и неизвестных пользователей;
- отображение рамки и имени пользователя на видео;
- запись даты, времени и статуса присутствия в файл `Attendance.csv`;
- тестирование работы системы при плохом освещении, частично закрытом лице и нескольких лицах в кадре.

## Используемые технологии

- Python
- OpenCV
- Dlib
- face_recognition
- NumPy
- CSV
- Web camera

## Тестирование

В ходе тестирования была проверена работа системы в нескольких сценариях:

- распознавание зарегистрированного пользователя;
- определение неизвестного лица;
- запись данных в файл посещаемости;
- работа при плохом освещении;
- распознавание при частично закрытом лице;
- распознавание нескольких лиц одновременно.

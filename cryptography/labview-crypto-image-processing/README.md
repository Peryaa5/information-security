# LabVIEW Crypto Image Processing

Проект реализует криптографическую обработку изображения в среде LabVIEW: загрузку BMP-изображения, преобразование его в двоичную последовательность, шифрование, хеширование, формирование и проверку электронной цифровой подписи, а также восстановление исходного изображения.

## Реализованные функции

- Загрузка изображения в формате `.bmp`
- Преобразование изображения в двоичную последовательность
- Поточное шифрование данных с использованием упрощённого RC4
- Формирование хеш-кода на основе CRC-16
- Формирование электронной цифровой подписи по схеме RSA
- Вычисление секретного ключа RSA с использованием расширенного алгоритма Евклида
- Быстрое двоичное возведение в степень
- Проверка корректности ЭЦП
- Расшифрование данных
- Восстановление изображения после криптографических преобразований

## Технологии

- LabVIEW
- RC4
- CRC-16
- RSA
- BMP image processing

# Альфа CTF 2026 — selected writeups

В этой папке собраны мои разборы отдельных заданий с Альфа CTF 2026.  
Это не полный разбор всех задач соревнования, а подборка решённых заданий из разных категорий.

## Разобранные задания

| № | Задание | Категория | Основная идея |
|---|---------|-----------|---------------|
| 1 | Кот | Web / Clientside | Анализ HTML/CSS/Canvas, снятие визуального размытия |
| 2 | Долбит нормально | Forensics / PPTX | Разбор структуры PPTX как ZIP-архива, поиск данных в XML |
| 3 | Новая куртка | Infra / Linux / SSH | Анализ поведения shell/readline и выхода в редактор |
| 4 | Шоколадный дроп | Web / JavaScript | Ошибка логики обработки промокода и баланса |
| 5 | Углеродный след | Pwn / Memory | Перезапись данных через некорректную работу курсора |
| 6 | Скрытый таск | Misc / Stego | Расшифровка скрытого сообщения через Брайль |

## Использованные навыки

- анализ клиентской части веб-приложений;
- работа с DevTools и JavaScript;
- разбор структуры `.pptx` через ZIP/XML;
- поиск скрытых данных в файлах;
- базовый анализ Linux/SSH-окружения;
- понимание ошибок логики в веб-приложениях;
- базовый анализ ошибок работы с памятью;

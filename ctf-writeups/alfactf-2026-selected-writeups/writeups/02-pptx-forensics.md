# Задание 2 — Долбит нормально

> **Альфа CTF 2026**

> Статус: решено  
> Формат: краткий writeup для портфолио

## Описание

В задании был выдан файл презентации в формате `.pptx`. На первый взгляд это обычная презентация, которую можно открыть через PowerPoint или другой просмотрщик.

Но в forensics-задачах важно смотреть не только видимую часть файла, но и его внутреннюю структуру.

## Основная идея

Файл `.pptx` — это не просто презентация. На самом деле это ZIP-архив, внутри которого находятся XML-файлы, изображения, стили, связи между объектами и другие служебные данные.

Поэтому такой файл можно распаковать и изучить как обычный архив.

## Ход решения

### 1. Распаковка PPTX

Сначала я создала отдельную папку для распаковки файла:

```bash
mkdir pptx_unpack
```

Затем распаковала `.pptx` как архив:

```bash
unzip resona_subwoofer_manual.pptx -d pptx_unpack
```

После этого появилась внутренняя структура презентации.

### 2. Просмотр структуры файла

Чтобы посмотреть все файлы внутри распакованной презентации, я использовала команду:

```bash
find pptx_unpack -type f
```

Внутри презентации можно увидеть папки с XML-файлами, слайдами, изображениями и служебной информацией.

Основной интерес представляла папка со слайдами:

```text
pptx_unpack/ppt/slides/
```

### 3. Извлечение текста из слайдов

Текст в презентации хранится внутри XML-файлов слайдов. Обычно он находится в тегах:

```xml
<a:t>...</a:t>
```

Чтобы быстро вытащить текст из всех слайдов, я использовала цикл:

```bash
for f in pptx_unpack/ppt/slides/slide*.xml; do
  echo "===== $f ====="
  grep -oP '(?<=<a:t>).*?(?=</a:t>)' "$f"
done
```

Эта команда проходит по всем XML-файлам слайдов и выводит текст, который находится внутри тегов `<a:t>`.

### 4. Поиск скрытого сообщения

После извлечения текста стало понятно, что нужная информация была разбита на части и спрятана среди текста презентации.

Чтобы быстрее найти конец флага, я искала символ:

```text
}
```

Так удалось найти фрагменты скрытого сообщения и собрать итоговый ответ.

Флаг в публичной версии writeup не указывается:

```text
flag{...}
```

## Почему это сработало

Презентации `.pptx` хранят содержимое не в одном цельном файле, а в наборе XML-документов внутри архива. Даже если текст неочевидно отображается на слайдах или разбит на части, его можно найти через анализ внутренней структуры файла.

Для forensics-задач это важный подход: смотреть не только то, что видно при открытии файла, но и то, как файл устроен внутри.

## Использованные инструменты

- Linux terminal
- `mkdir`
- `unzip`
- `find`
- `grep`
- анализ XML
- поиск по тексту

## Краткий вывод

Задание показало, что офисные документы могут содержать скрытую или разбитую на части информацию внутри своей структуры.  
Вместо обычного просмотра презентации нужно было распаковать `.pptx`, изучить XML-файлы слайдов и найти нужные фрагменты текста.
